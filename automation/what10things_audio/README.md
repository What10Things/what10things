# What10Things Audio

This feed is the audio-only derivative of ordinary What10Things long-form
explainers. It is separate from Night Atlas:

- **Night Atlas** receives sleep-format long-form episodes.
- **What10Things Audio** receives standard long-form explainers.

The same approved narration is reused, so podcast distribution does not require
another script-writing or TTS pass.

Public endpoints after deployment:

- `https://what10things.co.uk/what10things-audio/`
- `https://what10things.co.uk/what10things-audio/rss.xml`
- `https://what10things.co.uk/what10things-audio/cover.png`

Episodes remain empty until the Brain's distribution step has a stable public
audio enclosure URL. The feed must never point at an authenticated or temporary
Dropbox URL.
